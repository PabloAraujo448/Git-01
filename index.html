Aula Prática — Conta de Estudante @etec.sp.gov.br(ETEC) no GitHub

Guia passo a passo com ilustrações didáticas para criar conta, solicitar o Student Pack, subir projetos e publicar com GitHub Pages.

Objetivo

Ao final desta aula o estudante saberá criar uma conta no GitHub usando o e‑mail institucional da ETEC, solicitar o benefício de estudante, fazer upload de projetos de site e publicar usando o GitHub Pages.

Sumário rápido

  • 1 — Criar conta no GitHub
  • 2 — Solicitar GitHub Student Developer Pack
  • 3 — Criar repositório
  • 4 — Fazer upload dos arquivos
  • 5 — Publicar com GitHub Pages

Passo a passo ilustrado

1. Criar conta no GitHub

  1. Acesse github.com e clique em Sign up.
  2. Preencha: Email: use seu e-mail institucional da ETEC (ex.: nome.sobrenome@etec.sp.gov.br),
    Senha: crie uma senha segura.
    Username: Ex Aluno1234567
    3. Clique em Sign up (no canto superior direito).
  3. Confirme o e‑mail clicando no link enviado.
Exemplo de tela: formulário de criação de conta.

2. Solicitar o GitHub conta de estudante

  1. Acesse education.github.com/pack e clique em " Your benefits application "no canto superior direito.
  2. Faça login com sua conta GitHub e escolha Student.
  3. Preencha o formulário e anexe comprovante de matrícula ou carteirinha.
  4. Aguarde a aprovação (normalmente até 3 dias úteis).
Dica do professor: peça aos alunos que guardem uma foto ou PDF da carteirinha para anexar rapidamente.

3. Criar repositório para o projeto

  1. No seu Perfil do GitHup clique em Repositorio ->+ → New repository.
  2. Nomeie o repositório (ex.: meu-site-etec), marque Public e adicione um README.
  3. Clique em Create repository.

4. Fazer upload dos arquivos do site

  1. Dentro do repositório clique em Add file → Upload files.
  2. Arraste e solte index.html, style.css, imagens e pastas.
  3. Clique em Commit changes.
Ilustração: área de upload de arquivos dentro do repositório.

5. Publicar com GitHub Pages

  1. Vá em Settings → Pages no repositório.
  2. Em Source, escolha Deploy from a branch, selecione main e clique em Save.
  3. Em alguns minutos seu site estará disponível em https://seuusuario.github.io/meu-site-etec.
Exemplo: configuração do GitHub Pages (seletor de branch e pasta).

Dicas pedagógicas & checklist para o professor

  • Peça que cada aluno crie um repositório por projeto — facilita avaliação.
  • Verifique se o index.html está na raiz do repositório para o Pages funcionar.
  • Mostre como usar o README.md para descrever o projeto.
  • Exercício rápido: publicar uma página com apenas um arquivo index.html.
